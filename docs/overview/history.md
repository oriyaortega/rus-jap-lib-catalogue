# История проекта

Краткая хронология. Подробности каждого изменения есть в журнале git (`git log`), а сводки для читателей — в поле `news` каталога.

## 8 ноября 2026 — прототип и первые данные

- Рассмотрели варианты реализации (своя база, Википедия, гибрид). Выбран гибрид: выходные данные книг хранятся в своём JSON, сведения о людях подгружаются из Викиданных и Википедии.
- Дизайн менялся несколько раз:
  1. по образцу hkcinema.gotar.ru;
  2. аскетичный, без жёлто-красного;
  3. на основе каруты;
  4. добавлен цветной вариант с переключателем.
- Добавлены разделы «Нехудожественная литература» и «Переводчики».
- Описания из Викиданных больше не показываются: в описании Б. Акунина нашли шуточный вандализм. См. [Викиданные](../data-collection/wikidata-wikipedia.md).
- Первые 13 демонстрационных книг (b1–b13) сверены с Фантлабом.
- Импорт из многих источников, подробности в [Источниках](../data-collection/sources.md):
  - Фантлаб (серия «Библиотека японской литературы», переводы Рябовой и Байбиковой);
  - «Поляндрия NoAge», «Лабиринт» (Orientalia et Classica, «Гиперион»);
  - ВШЭ (Щепкин, Мещеряков) и Википедия (Штейнер, Мещеряков);
  - таблица xlsx составителя, Google-таблица составителя;
  - «Азбука», «Бомбора», МИФ, LiveLib.
- На всех страницах показываются серия и ISBN.

## Начало ноября — доработка разделов

- Главная: «Последние добавления» и «Новейшие издания».
- Авторы:
  - имена в оригинале на карточках;
  - Е и Ё — разные буквы;
  - переключатель «Карточки / Список»;
  - кириллица на карточках повёрнута, читается снизу вверх.
- Произведения: сортировка по году создания, отдельная таблица «Неяпонские авторы».
- Издания, Нехудожественная литература, Поиск:
  - переключатель вида и сортировки;
  - теги «бизнес», «экономика», «политика», «детская литература», «театр кабуки».

## Хостинг и картинки

- Проект выложен в репозиторий `oriyaortega/rus-jap-lib-catalogue`, включён GitHub Pages.
- Все обложки и портреты скачаны в `images/`, потому что часть российских сайтов недоступна без VPN. Сайт показывает локальные копии. См. [Картинки](../technical/images.md).
- Сайт всегда светлый, независимо от системной темы. Подвал страниц убран.

## Каталог ИВ РАН и сведения об авторах

- 286 книг из каталога book.ivran.ru (iv*), отдельные карточки с orientalstudies.ru (h1–h7).
- Работа с отдельными карточками: Пак (Пушакова), Щепкин, Конрад, Жуков (zh*), Эйдус (ed*, псевдоним У. Хаяма).
- Поиск биографий и портретов для всех авторов без сведений, обложек для книг без обложек. Подробнее: [Биографии](../data-collection/bios.md).
- Русские имена больше не дублируются латиницей. Появились псевдонимы и отсылки с псевдонима в перечне авторов (поле `aliases`).

## 9 ноября — печатные библиографии

- 2220 книг из трёх томов «Библиографии Японии» (1734–1917, 1917–1958, 1959–1973), префиксы bja/bjb/bjc. См. [Печатные библиографии](../data-collection/pdf-bibliographies.md).
- Карточки каруты: название больше не наезжает на жанр, японские цифры для номеров от 1000.
- Мещеряков: биография и портрет с сайта ВШЭ. Марчук: биография, 4 книги и обложки с sengoku.ru, «Золотого сечения» и LiveLib.

## 23 ноября — Ad Marginem и японисты из Википедии

- 16 книг Ad Marginem: Рёко Секигути и серия «hide books». См. [Источники](../data-collection/sources.md).
- 411 японистов из «Списка русскоязычных японистов» и категорий Википедии, 797 их книг (wj*). См. [Японисты из Википедии](../data-collection/wikipedia-japanologists.md).
- На странице автора книги идут по алфавиту. Псевдонимы вынесены из названий в примечания.
- Создана эта документация, скрипты импорта восстановлены в `docs/scripts/`.

## 24 ноября — React + TypeScript

- Сайт переписан на React 19 + TypeScript со сборкой Vite, разбит на компоненты; логика вынесена в `src/lib/` и покрыта тестами vitest. Вид, адреса и данные не изменились — это проверено сверкой со старой версией в Chrome. См. [Переход на React](../technical/react-version.md).
- Новая версия заменила старую в корне репозитория (`index.html`, `app.js`, `styles.css` удалены; старая версия — в истории git).
- Публикация на GitHub Pages — через GitHub Actions: сборка при каждом push в `main`, статика в git не хранится.
- Ленивая отрисовка длинных списков: записи подгружаются при прокрутке; открытие тяжёлых страниц ускорилось с 0,5–0,7 с до 0,1 с. В «Изданиях» появилась сортировка по дате добавления. См. [Страницы и функции](../technical/pages.md).
- В «Изданиях» сортировку можно развернуть повторным нажатием (по возрастанию или убыванию); в виде «Список» заголовки столбцов таблицы сортируют, в том числе по автору и серии.
