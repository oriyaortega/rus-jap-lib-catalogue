# Оформление (карута)

Дизайн основан на японской карточной игре карута, по образцу «Хякунин иссю». Как менялось оформление, см. в [Истории](../overview/history.md).

## Элементы

- **Шапка** (`.masthead`): карточка-логотип 百 / 日本文学, повёрнутая на −4°, надпись にほんぶんがく · かるた и название сайта.
- **Хэри** (`.heri`): декоративная полоса под шапкой, как кайма татами.
- **Фон** — цвет татами (`--tatami`).
- **Торифуда** (`Fuda` в `src/components/cards.tsx`) — карточка книги с пропорциями 52:73:
  - `.fuda-no` — номер японскими цифрами;
  - `.fuda-v` — вертикальное название: японское `title_orig` или русское с классом `ru`;
  - `.fuda-foot` — жанр;
  - если есть обложка, вместо надписей показывается `img.cover-img` (класс `has-cover`).
- **Ёмифуда** (`Yomifuda`) — карточка человека: портрет (или первая буква имени) и вертикальное имя в оригинале.
- **Колода** (`BookDeck`, `PeopleDeck`) — сетка `auto-fill, minmax(150px, 1fr)`, на телефоне два столбца, под карточками подписи.

## Шрифты

Google Fonts:
- Shippori Mincho — японский текст и заголовки;
- Noto Serif — основной текст (`--serif`);
- Noto Sans.

## Название на карточке

Русское название не должно наезжать на номер и жанр. Решение, принятое после исправления карточки «Рабочее движение в Стране восходящего солнца»:

```css
.fuda:not(.yomi):not(.has-cover) { padding: 24px 8px 26px; }   /* место между номером и жанром */
.fuda:not(.yomi) { container-type: inline-size; }
.fuda:not(.yomi) .fuda-v.ru { font-size: clamp(9px, 10cqw, 13px); }
.fuda:not(.yomi) .fuda-v.ru.long { font-size: clamp(8px, 8.5cqw, 11px); }  /* названия длиннее 100 знаков */
[data-palette="color"] .fuda:not(.yomi):not(.has-cover) { padding-top: calc(19.7% + 10px); }
```

Здесь используется `cqw`, а не `cqi`: при вертикальном письме ось inline у контейнера тоже вертикальная, и `cqi` даёт не то значение.

## Палитры

- **Монохромная** (по умолчанию): светлый татами `#ece7d2`, карточки `#fbf8ef`, тушь `#1d1c19`, кайма — сосновый зелёный `#2e4a3c`, золотая линия `#b59a5b`.
- **Цветная**: включается кнопкой «Цвет», сохраняется в `localStorage.palette`, задаётся атрибутом `html[data-palette="color"]`.
  - Карточки книг окрашены по жанру (`GENRE_COLORS` в `src/lib/colors.ts`) традиционными японскими цветами:
    - роман 藍, повесть 若竹, новеллы 柿, дзуйхицу 藤, моногатари 紅, поэзия 桃, очерки 鶯;
    - исследование 鉄紺, драма 樺, сказки 山吹, манга 撫子, история 焦茶, искусство 縹, справочник 鼠, учебник 柳.
  - Карточки авторов окрашены по эпохе (`ERA_COLORS`):
    - Хэйан 紅, Камакура 黄櫨, Муромати 御納戸, Эдо 柿, Мэйдзи 藍, Тайсё 藤, Сёва 若竹, современность 青碧;
    - неяпонские авторы — оливковым;
    - переводчики — 江戸紫.
  - Легенды цветов (`components/Legend.tsx`) показываются только в цветной палитре. Легенда эпох — только в перечне авторов: у переводчиков кайма всегда одного цвета.

Добавляя новый жанр, добавьте ему цвет в `GENRE_COLORS`. Иначе карточка будет серой (`#5b5b5b`).

## Тема

Сайт всегда светлый: `color-scheme: only light` в `:root` и `<meta name="color-scheme" content="only light">`. Тёмные палитры удалены по просьбе составителя: сайт должен выглядеть одинаково при любой системной теме.

## Адаптивность

Все страницы проверены на ширине 375 px: нет горизонтальной прокрутки, переключатели переносятся (`flex-wrap`, `white-space: nowrap` у пунктов). Профиль на телефоне в один столбец.
