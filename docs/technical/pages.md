# Страницы и функции сайта

## Ленивая отрисовка длинных списков

Длинные списки рисуются порциями: сначала первые 48 карточек книг (96 карточек людей, 150 строк таблицы или списка), следующие — когда до конца отрисованного остаётся около полутора тысяч пикселей (`IntersectionObserver` на метке `.lazy-sentinel`). Так устроены перечни авторов и переводчиков, «Произведения», «Издания», «Нехудожественная литература», «Поиск», страницы автора, переводчика и серии.

- Хук — `src/hooks/useProgressive.tsx`, расчёты (какие группы и сколько показывать) — `src/lib/progressive.ts`.
- Новый запрос, теги, вид или сортировка — список снова начинается с первой порции.
- Навигация по буквам сначала дорисовывает список до нужной буквы, потом плавно прокручивает к ней.
- Заголовки и счётчики («Найдено: 4001», «Японские авторы · 779») считаются по всему списку. Раздел «Неяпонские авторы» в «Произведениях» и список произведений на странице автора появляются, когда предыдущий список показан до конца.
- Поиск по странице в браузере (Ctrl+F) находит только уже отрисованное.
- Для отладки и сверки ленивую отрисовку можно отключить: `localStorage.lazy = 'off'` — тогда всё рисуется сразу.

Замеры на собранной версии (24 ноября 2026 г.): открытие страницы с нуля — около 100 мс для любой страницы (было до 730 мс у «Изданий» и 674 мс у «Поиска»), переход между страницами внутри сайта — 6–25 мс; на странице 500–1300 элементов вместо 15–37 тысяч. Скрипты замеров: `tools/measure-load.js` (открытие с нуля) и `tools/measure.js` (переходы).

Маршруты и устройство приложения описаны в [Архитектуре](architecture.md), поля данных — в [Модели данных](data-model.md).

## Главная (`pages/Home.tsx`)

- **«Последние добавления»**: 5 книг с самой поздней датой `added`. При равной дате выше книга с большим номером карточки.
- **«Новейшие издания»**: 12 книг с самым поздним годом издания, текстовой колонкой.
- Легенда цветов жанров видна только в цветной палитре.

## Авторы и переводчики (`pages/People.tsx` → `components/LettersPage.tsx`)

- Сортировка по `sort` с помощью `alphaCompare` (`lib/text.ts`): Ё считается отдельной буквой после Е, латиница идёт после кириллицы.
- Над перечнем — навигация по буквам.
- Переключатель «Карточки / Список» (`?view=list`).
- На карточке имя в оригинале: иероглифы вертикально, кириллица и латиница повёрнуты, чтобы читались снизу вверх (`writing-mode: sideways-lr`).
- Псевдонимы из `aliases` выводятся отдельной строкой с подписью «псевдоним; см. …» и ведут на основную карточку.

## Страница автора (`pages/Author.tsx`)

- Профиль (`components/Profile.tsx`, строки сведений — `lib/people.ts`):
  - портрет и заголовок; у русских авторов это полное имя;
  - строка «Имя в оригинале»; «Латиницей» — только для нерусских имён;
  - псевдоним или настоящее имя;
  - годы жизни и место рождения из Викиданных;
  - биография (своя или из Википедии) и ссылки.
- «Издания на русском»:
  - книги сгруппированы в произведения по `title_orig`, а если его нет — по `title_ru`;
  - **произведения идут по алфавиту названий**, кавычки и прочие знаки в начале не учитываются (`authorWorks` в `lib/grouping.ts`);
  - издания внутри одного произведения идут по году;
  - книги с `hide_on_author` пропускаются.
- «Произведения на русском языке»: список из `works`, по алфавиту.

## Страница переводчика (`pages/Translator.tsx`, группировка — `lib/translator.ts`)

Книги сгруппированы по авторам. Для сборников учитываются только те авторы, чьи вещи перевёл именно этот переводчик (по `contents[].tr`). Внутри группы книги идут по году.

## Произведения (`pages/Works.tsx`, фильтр и сортировка — `lib/works.ts`)

- Две таблицы: «Японские авторы» и «Неяпонские авторы» (`foreign: true`, с колонкой «Язык»).
- Сортировка по номеру, названию, автору и году создания. Есть поиск по таблице (`wq`) и фильтр по виду (`wkind`).
- Название ведёт на страницу произведения (`#/work/:id`). Так же устроен список «Произведения на русском языке» на странице автора.

## Произведение (`pages/Work.tsx`, логика — `lib/workPage.ts`)

- Оформлено как страница книги: слева карточка (вертикальное оригинальное название, год создания японскими цифрами, вид; цвет — по виду произведения, `kindColor`), справа таблица сведений: автор, оригинал и транскрипция, вид, год создания, переводчики, другие названия, число изданий в каталоге, ссылка на Фантлаб.
- «В каталоге» — карточки книг каталога с этим произведением (`catalogBooksOfWork`):
  - книги из поля `books` произведения;
  - книги того же автора, если оригинальное или русское название совпадает с названием книги или одной из его частей («Слушай песню ветра. Пинбол 1973», «竹取物語・落窪物語»);
  - сборники, в содержании которых оно есть;
  - издания Фантлаба, сопоставленные с книгами каталога (`book`);
  - у произведений без автора — поиск по всему каталогу.
- «Публикации на русском» — все книги и журналы по данным Фантлаба (`data/work-editions.json`), по годам. Название ведёт на книгу каталога, если она есть (отметка «в каталоге»), иначе — на издание на Фантлабе.
- Переводчики: из каталога (поле `translators`, содержание сборников, отдельные издания) и с Фантлаба. Имена с Фантлаба («Вадим Смоленский») сопоставляются с переводчиками каталога («Смоленский Вадим») по набору слов; найденные — ссылки.
- `data/work-editions.json` загружается один раз, при первом открытии страницы произведения (`hooks/useWorkEditions.ts`).

## Издания (`pages/Editions.tsx`, сортировки и группы — `lib/grouping.ts`)

- По умолчанию — карточки с обложками в алфавитном порядке. Можно переключить на список.
- Сортировка кнопками над списком: по алфавиту, году, издательству или **дате добавления** (`?sort=added`). Последняя — по номеру карточки, группы по дате добавления («добавлены 23 ноября 2026»). Номера карточек идут в порядке внесения книг, поэтому их порядок совпадает с датами (`added`).
- В виде «Список» заголовки столбцов таблицы — тоже кнопки сортировки, как в «Произведениях»: «Название», «Автор» (`?sort=author`, по фамилии первого автора), «Издательство», «Год», «Серия» (`?sort=series`, внутри серии — по номеру выпуска). Они меняют адрес без новой записи в истории и без прокрутки наверх. Сортировок по автору и серии среди кнопок над списком нет; если выбрать их в таблице и переключиться на карточки, карточки останутся в этом порядке.
- Направление: повторное нажатие на выбранную сортировку (кнопку или заголовок столбца) меняет его. Выбранная отмечена ▴ (по возрастанию) или ▾ (по убыванию), в адресе — `?order=asc|desc`, если направление не обычное. Обычное направление — по возрастанию, а для даты добавления — по убыванию (новые сверху). Книги без года, издательства, автора или серии всегда в конце, книги с одинаковым ключом — всегда по алфавиту названий (`editionComparator`).
- Книги разбиты на группы с заголовками; в заголовке — число книг всей группы, даже если она ещё отрисована не целиком. При сортировке по алфавиту и по автору есть навигация по буквам.
- Выбор года — простой перечень лет, в которые есть книги (`#/editions/1974`).

## Нехудожественная литература (`pages/Nonfiction.tsx`)

- Группы в фиксированном порядке: история, исследование, искусство, очерки, справочник, учебник.
- Сортировка внутри групп — такая же, как в «Изданиях» (`EditionSortSwitch` и `editionSortState` в `components/switches.tsx`): кнопки по алфавиту, году, издательству, дате добавления; в виде «Список» — заголовки столбцов таблицы; повторное нажатие меняет направление (`?order=asc|desc`). Разбивка на группы по жанру при этом сохраняется, отдельных групп по букве, году или издательству нет.
- Тематические теги, включая всегда видимые (`TOPIC_TAGS` в `lib/tags.ts`). Теги без книг показываются неактивными.

## Поиск (`pages/Search.tsx`)

- Текстовый поиск по нормализованному индексу (см. [Архитектуру](architecture.md#поиск)).
- Облако тегов: выбранные теги объединяются условием «И». Теги из `ALWAYS_TAGS` видны, даже если книг по ним нет («театр кабуки»).
- Сортировки `CatalogModel.bookSorts` (`lib/model.ts`): по автору, по названию, по году, по издательству; переключатель вида — как в остальных разделах.

## Страница книги (`pages/Book.tsx`)

- Карточка-торифуда, заголовок, оригинальное название, примечание.
- Таблица полей:
  - автор(ы) с иероглифами, оригинал, год оригинала, перевод;
  - место, издательство, год (ссылка на издания этого года), страниц, серия, ISBN, тираж;
  - жанр, теги (ссылки на поиск);
  - «Карточка» — номер японскими цифрами и арабскими;
  - «Источник».
- Содержание сборника. Если в нём больше 60 позиций, оно сворачивается. Название каждого произведения — ссылка на его страницу; японское название в содержании не повторяется (оно есть на странице произведения).
  - Пункт содержания относится к произведению из `works` с тем же автором и тем же оригинальным или русским названием (`contentWorks` в `lib/workPage.ts`). Если автор пункта не указан, берётся единственный автор книги.
  - Для остальных пунктов (их большинство: из 1637 пунктов в `works` есть около 170) страница произведения создаётся по самому содержанию: одна на автора и название, адрес — `#/work/c-<книга>-<номер пункта>` по первому упоминанию. На ней — название, оригинал, вид, переводчики и сборники, где оно есть. Адрес не изменится, пока книги добавляются в конец каталога и содержание не переставляется.
- «Другое издание» / «Другие издания» (`OtherEditions`): обложка и выходные данные других изданий, год — ссылка.

## Серия (`pages/Series.tsx`)

Книги серии в порядке номеров, сведения о серии (издательство, годы, примечание).

## Номер карточки

`kanjiNum(n)` (`src/lib/text.ts`) записывает номер японскими цифрами с разрядами 千, 百 и 十. Например, 二百八十二 — № 282. Номер равен позиции книги в массиве, см. [Архитектуру](architecture.md#запуск).
