# Модель данных: `data/catalog.json`

Кроме каталога есть файл публикаций произведений `data/work-editions.json` — см. [ниже](#публикации-произведений-dataworkeditionsjson).

Один JSON-объект в UTF-8 с отступом в 1 пробел. Его удобно править скриптами на Python: `json.load` → изменения → `json.dump(c, f, ensure_ascii=False, indent=1)`. Так диф в git остаётся маленьким. См. [Как вносить изменения](../maintenance/how-to.md).

## Книга (`books[]`)

| Поле | Тип | Описание |
|---|---|---|
| `id` | строка | уникальный id; префикс указывает на источник, см. [Источники](../data-collection/sources.md) |
| `title_ru` | строка | название по-русски |
| `title_orig` | строка или null | название в оригинале, **только японское**, потому что карточка выводит его вертикально как японский текст. Европейские оригинальные названия пишутся в `work_note` |
| `title_romaji` | строка или null | транскрипция японского названия |
| `authors` | массив id | авторы (`authors[].id`) |
| `translators` | массив id | переводчики (`translators[].id`) |
| `year` | число или null | год издания; null показывается как «б. г.» |
| `city`, `publisher` | строка или null | место и издательство |
| `pages` | число или null | число страниц |
| `isbn` | строка | если не указан, на странице книги показывается «не указан» |
| `print_run` | число | тираж |
| `series` | `{id, no}` | серия (`series[].id`) и номер в ней |
| `genre` | строка | жанр; от него зависят цвет карточки и группа в «Нехудожественной литературе» |
| `orig_year` | строка или null | время создания оригинала, например «X–XIV вв.» |
| `tags` | массив строк | теги. Типовые: `художественная`, `нехудожественная`, `переводная`, `на русском`. Остальные — темы и эпохи |
| `work_note` | строка | аннотация или примечание: другие издания, псевдоним, оригинальное название |
| `contents` | массив | содержание сборника: `{a: id автора или null, at: подпись автора, t: название, o: оригинал, k: вид, tr: [id переводчиков], p: страницы}` |
| `editions` | массив | другие издания этой книги: `{title, city, publisher, year, pages, isbn, size, binding, note, book: id отдельной карточки, cover, cover_src, source}` |
| `hide_on_author` | true | не показывать книгу на странице автора, например если это издание уже показано в «Другом издании» |
| `cover` | строка | путь к локальной обложке `images/cover_<id>.<ext>` |
| `cover_src` | строка | откуда скачана обложка |
| `source` | URL | основная страница-источник; название сайта для неё определяет `sourceName()` в `src/lib/sources.ts` |
| `sources` | массив строк | дополнительные источники: ключи из `SOURCE_NAMES` (`xlsx`, `gsheet`, `fantlab`, `polyandria`, `labirint`, `hse`, `wikipedia`, `azbuka`, `bombora`, `livelib`, `mif`, `alpina`, `ivran`) **или** готовый текст, например «Библиография Японии… (М., 1965), № 5752» |
| `links` | массив `{name, url}` | дополнительные ссылки: скан, PDF, страница издательства |
| `added` | дата `ГГГГ-ММ-ДД` | когда внесена; по этому полю строится список «Последние добавления» |

Все строки «Источник» на странице книги собираются из `source`, `links` и `sources`.

## Автор (`authors[]`)

| Поле | Описание |
|---|---|
| `id` | id. Ранние — латиницей по фамилии (`murakami`, `konrad`). Для импортированных — транслит фамилии и имени (`marchukivan`) или хеш (`iva6b9ae0bd`) |
| `name_ru` | «Фамилия Имя» |
| `sort` | ключ сортировки, обычно фамилия |
| `name_orig` | имя в оригинале: иероглифы для японцев, латиница для иностранцев. `null` — у человека нет «оригинального» имени (русские авторы); тогда японская метка из Викиданных не используется |
| `full_name` | полное имя с отчеством; у русских авторов показывается заголовком страницы |
| `wikidata` | QID (`Q4181364`) или null |
| `bio`, `bio_src {name, url}` | своя биография и её источник; если есть, заменяет текст Википедии |
| `image`, `image_src` | локальный портрет и откуда он скачан |
| `links` | дополнительные ссылки `{name, url}`. Ссылку на Википедию добавлять не нужно, сайт ставит её сам по `wikidata` |
| `pseudonym`, `real_name` | псевдоним или настоящее имя, выводятся строкой в профиле |
| `aliases` | `[{name_ru, sort}]`: дополнительные записи в перечне авторов («Хаяма У.» со ссылкой на Эйдуса) |
| `era` | эпоха для цвета карточки (Хэйан, Камакура, Муромати, Эдо, Мэйдзи, Тайсё, Сёва, современность). Если не задана, вычисляется по году рождения |
| `hide_latin` | не показывать строку «Латиницей» |

## Переводчик (`translators[]`)

`id`, `name_ru`, `short` («Г. Чхартишвили»), `sort`, `wikidata`, и при наличии `image`, `image_src`, `bio`.

Один и тот же человек может быть и автором, и переводчиком. Тогда у него две записи с разными id.

## Серия (`series[]`)

`{id, name, publisher?, city?, years?, note?, source?}`. Поле `source` сайт подписывает как «Фантлаб», поэтому другие URL туда не пишут. Большинство серий содержат только `id` и `name`.

## Произведение (`works[]`)

Список произведений японских авторов (по Фантлабу) и иностранных авторов о Японии:

- общие поля: `{id, authors, title_ru, title_orig, title_romaji, kind, year, fantlab}`;
- у иностранных авторов: `foreign: true`, `lang`, `books: [id книг]`;
- у нескольких анонимных произведений без Фантлаба (`xw1`…): `translators: [id переводчиков]`;
- `wc-<id книги>` — произведения, созданные 26 ноября 2026 г. по художественным изданиям, которые не относились ни к одному произведению: без `fantlab`, с `books: [id книг]` (все издания этого произведения в каталоге); у иностранных авторов — `foreign: true`. Виды: роман, повесть, сборник (книги «Избранное», «Рассказы»…), антология (без автора или нескольких авторов), сказки, моногатари, дзуйхицу и др.

Манги и комиксов в `works` нет (виды «манга», «комикс», «графический роман» и циклы манги удалены 26 ноября 2026 г.); книги манги остаются в «Изданиях». Каждое художественное издание, кроме манги, относится хотя бы к одному произведению — это проверяет `catalog-regression.test.ts`.

Сайт дополняет этот список произведениями из содержания сборников, которых в `works` нет (`derived: true`, в файле их нет), см. [Страницы и функции](pages.md).

Используется в разделе «Произведения», на странице произведения и в блоке «Произведения на русском языке» на странице автора.

## Публикации произведений: `data/work-editions.json`

Отдельный файл (около 0,7 МБ), который сайт загружает только при первом открытии страницы произведения. Собран по API Фантлаба, см. [скрипты](../scripts/README.md#fantlab).

```
{ "<id произведения>": {
    "tr": ["Вадим Смоленский", …],          // переводчики на русский (по Фантлабу)
    "titles": ["Расёмон"],                   // другие русские названия переводов
    "pubs": [ { "fl": 6673,                  // номер издания: fantlab.ru/edition6673
                "title": "Слушай песню ветра. Пинбол 1973",
                "kind": "книга" | "журнал",
                "year": 2002, "publisher": "Эксмо", "pages": 384,
                "tr": ["Вадим Смоленский"],  // переводчики в этом издании
                "book": "az12" } ] } }        // то же издание в каталоге (по ISBN или году, названию и автору)
```

Берутся издания и периодика на русском; аудиокниги, самиздат, планы издательств и иностранные издания пропускаются. Файл пересобирается целиком; правки вручную при пересборке пропадут.

## Новости (`news[]`)

`{date, text}`. Вставки вида `{author:id}` задумывались как ссылки на автора. Раздел «Новости» с главной убран по просьбе составителя, и сейчас сайт эти записи не выводит. Их всё равно добавляют при каждом крупном импорте: это журнал изменений, понятный без git.
