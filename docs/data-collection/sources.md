# Источники

Каждая книга несёт отметку об источнике: `source` (URL), `sources` (ключ или текст) или `links`. Префикс id книги показывает, при каком импорте она появилась. Общий порядок работы: [Обзор процесса](README.md).

## Сведения о людях

- **Викиданные и Википедия**: QID у 482 авторов. Годы, место рождения, имена, портреты, вступления статей. См. [Викиданные](wikidata-wikipedia.md).
- **Страницы организаций**: ВШЭ (hse.ru/org/persons/…), ИВР РАН, ИВ РАН, «Альпина», МИФ, sengoku.ru, Ad Marginem.
- **Викитека**: Эйдус.
- **Perplexity**: поиск сведений о малоизвестных авторах, с проверкой каждого факта. См. [Биографии](bios.md).

## Как сайт подписывает источник

- `sourceName(url)` в `src/lib/sources.ts` превращает URL в название: Фантлаб, Лабиринт, LiveLib, «сайт ВШЭ», «сайт ИВР РАН», «каталог ИВ РАН», «библиотека ДВФУ» и т. д. Неизвестный сайт подписывается «ссылка». Для нового частого источника добавьте правило.
- `SOURCE_NAMES` (там же) переводит короткие ключи из `sources`. Значения, которых нет в словаре, выводятся как есть.
- Для разовых ссылок с собственным названием («Ad Marginem», «PDF на sengoku.ru») используйте `links: [{name, url}]`.
