# Викиданные и Википедия

## Что сайт берёт сам при показе

Если у автора или переводчика заполнено поле `wikidata`, браузер загружает (см. [Архитектуру](../technical/architecture.md#викиданные-и-википедия-на-стороне-браузера)):

| Что | Откуда |
|---|---|
| имена `ru`, `ja`, `en`, псевдонимы | labels, aliases |
| кана | P1814 |
| даты рождения и смерти с учётом точности | P569, P570 |
| место рождения | P19, затем отдельный запрос его названия |
| портрет | P18 через `Special:FilePath?width=240`, если нет локального `image` |
| ссылки на статьи | sitelinks `ruwiki`, `jawiki` |
| биография | вступление статьи ruwiki через REST `page/summary`, если нет своего `bio` |

Описания (descriptions) из Викиданных **не показываются**. В описании Б. Акунина (Q125663) был шуточный вандализм («…переодетый человек-призрак с острова Смерть…»), и описания решено не выводить.

Ссылку на Википедию в `links` добавлять не нужно: сайт ставит её сам. Иначе она будет показана дважды.

## Имена в оригинале (`name_orig`)

Порядок, принятый при заполнении (скрипт [`apply_orig.py`](../scripts/wikidata/apply_orig.py)):

1. Японец: метка `ja` содержит иероглифы, страна — Япония или не указана → иероглифы.
2. Русские и советские авторы → `null` (оригинального имени нет). `null` прямо запрещает подставлять японскую метку: у Конрада в Викиданных есть «ニコライ・コンラド».
3. Остальные → имя на родном языке (P1559), иначе английская метка. Пояснения в скобках в конце отбрасываются.
4. Ручные поправки (`orig_manual.json`) важнее автоматики. Например, Исида Сё → 石田祥, а Судзуки Нобуо, Кано Хироко, Канэко Юми, Сиратори Кэндзи → `null` (найденные совпадения были ошибочными).

## Поиск QID

- **По статье Википедии** — самый надёжный способ. `action=query&prop=pageprops&titles=…` в ru или ja Википедии даёт `wikibase_item`. Подходят только элементы-люди (P31 = Q5).
- **SPARQL по точной русской метке** — для массового поиска. Один POST-запрос к `https://query.wikidata.org/sparql` на 60 имён (скрипты [`sparql_orig.py`](../scripts/wikidata/sparql_orig.py), [`wd_sparql.py`](../scripts/wikidata/wd_sparql.py)).
- **Проверять совпадение**. Ошибки бывали: `rybinvikto` сопоставился с музыкантом, однофамильцы с одинаковыми инициалами. При сомнении QID не ставится.
- Если два человека в каталоге получили один QID (Сэй-Сёнагон, Исса, Эдогава Рампо), это дубль, и записи объединяются.

## Полное имя

Из метки Викиданных полное имя берётся только в форме «Фамилия, Имя Отчество» (с запятой). Иначе порядок слов бывает неверным: у Конрада получалось «Николай Конрад». Надёжнее заполнять `full_name` вручную.

## Биографии из Википедии

Когда составитель просит взять сведения из статьи (Жуков, Мещеряков), вступление статьи кладётся в `bio`, а в `bio_src` пишется `{name: 'Википедия, CC BY-SA 4.0', url: <статья>}`. Портрет скачивается в `images/`. Если файл в ruwiki несвободный, составителю об этом говорится.
