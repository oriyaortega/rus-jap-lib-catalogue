# Биографии авторов

## Откуда берётся биография

1. **Своё поле `bio`** с источником `bio_src` — показывается в первую очередь.
2. Если его нет, но есть `wikidata` и статья в ruwiki, показывается вступление статьи (загружается в браузере).
3. Иначе биографии нет, видны только годы и место рождения из Викиданных, если они есть.

Сейчас своё `bio` есть у 612 авторов, `wikidata` — у 482. Примерно у 1176 авторов нет ни того, ни другого. В основном это авторы из печатных библиографий, известные только по инициалам.

## Поиск сведений через Perplexity

Используется для малоизвестных авторов, у которых нет статьи в Википедии.

- `perplexity_search` с `max_tokens_per_page` ≥ 256, **один человек на запрос**, в запросе — имя и известная книга из каталога.
- `perplexity_ask` на больших пачках выдумывает факты или отвечает пустотой, поэтому для этого не подходит.
- **Каждый факт проверяется** по найденной странице. Источник в `bio_src` — реальная страница, где этот факт написан, а не догадка о URL.
- Сомнительное отбрасывается. Ошибки, которые встречались: школа живописи Сико, отец Накацукасы, учёная степень Саркисова.
- Скрипт сборки биографий из пакетов: [`merge_bios.py`](../scripts/wikidata/merge_bios.py). В нём есть таблица «домен → название источника».

## Биографии из страниц организаций

Когда составитель даёт ссылку (ВШЭ, ИВР РАН, МИФ, «Альпина», sengoku.ru, Ad Marginem, Викитека), биография пишется своими словами по этой странице: должность, степень, область исследований, главные книги. `bio_src` — `{name: 'сайт НИУ ВШЭ', url}` и т. п.

## Биографии из «Списка японистов»

Для 411 японистов без статьи биография собрана автоматически из строки списка: «Зимонин Вячеслав Петрович (род. 1946) — японист, доктор исторических наук (1991)». См. [Японисты из Википедии](wikipedia-japanologists.md).

## Стиль

- Нейтральный справочный тон, без оценок.
- Первое предложение — кто это, затем деятельность и главные книги.
- Не повторять то, что сайт и так показывает (годы жизни при наличии Викиданных).
- Русские имена не дублируются латиницей.
