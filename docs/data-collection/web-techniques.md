# Приёмы работы с сайтами

Практические сведения о том, как удавалось получать данные с разных сайтов. Общий порядок: [Обзор процесса](README.md).

## Выбор способа

1. **`curl` или Python `urllib`** — для открытых страниц и API: Википедия, Викиданные, Фантлаб API, sengoku.ru, admarginem.ru, hse.ru. Указывайте осмысленный User-Agent, например `catalog-research/1.0 (personal bibliography project)`. Личные данные в User-Agent не пишите.
2. **Встроенный браузер** с JavaScript на странице (`fetch` с того же сайта, разбор DOM) — для сайтов, которые отдают 403 скриптам: LiveLib, Лабиринт, Google Books (лимиты).
3. **Ручная выгрузка** — если сайт требует входа: Google-таблица выгружается в CSV по ссылке `.../export?format=csv`, когда таблица открыта по ссылке.

## Как вынести данные из браузера

Публичный сайт не может отправить `fetch` на `localhost`: это запрещает Private Network Access. Рабочий приём, скрипт [`receiver.py`](../scripts/pipeline/receiver.py):

1. На странице-источнике собрать данные в JSON и положить в `window.name`.
2. Перейти в той же вкладке на `http://localhost:8767/`. `window.name` при переходе сохраняется.
3. Уже с локальной страницы отправить POST `/save?name=файл.json`, и приёмник сохранит его в `inbox/`.

Для небольших объёмов проще вернуть результат напрямую из `javascript_tool`.

## Российские сайты и VPN

- Лабиринт, LiveLib, ivran.ru, сайты издательств и их CDN картинок с этой машины часто недоступны без VPN: таймауты или 403. Картинки поэтому скачаны один раз с включённым VPN и хранятся в репозитории (см. [Картинки](../technical/images.md)).
- chitai-gorod.ru блокирует встроенный браузер, поэтому издательство для книги Марчука 2026 года найти не удалось.
- Лабиринт иногда зависает; помогает повторить позже.

## Ограничения и ошибки

| Сайт | Проблема | Решение |
|---|---|---|
| Викиданные API | 429 при частых поисках по имени | один SPARQL-запрос POST к query.wikidata.org пакетами по 60. GET со списком падает с 503 из-за длины URL |
| Google Books API | 429 | ISBN брать со страниц изданий LiveLib, сверяя год и издательство |
| LiveLib | 403 для скриптов; обложка в opengraph тоже 403; иногда обложка — SVG | работать в браузере через `fetch` с того же сайта; брать картинку вида `.../200x305/...` |
| Ad Marginem | 403/404 на кириллических URL файлов | имена файлов в Unicode NFD: «й» = «и» + U+0306, в URL `%D0%B8%CC%86` |
| hse.ru | портрет не в `<img>` | ссылка в `background-image` у миниатюры, размер `r380x380` |
| Google Docs | вкладка с документом не открывается в браузере | выгрузка CSV через `curl` |
| book.ivran.ru | ленивое регулярное выражение захватывало соседние записи списка | собирать id из области контента, затем разбирать страницы отдельных книг; роли людей — по `<strong>` |
| Фантлаб | — | API `https://api.fantlab.ru/work/{id}` даёт `work_year`; страницы изданий — `fantlab.ru/edition{N}` |

## Фоновая вкладка браузера

- Таймеры (`setTimeout`) в скрытой вкладке замедляются. Для длинных циклов `fetch` держите вкладку на переднем плане или обходитесь без пауз.
- Проверку сайта лучше вести в отдельной вкладке (`tabs_create`), чтобы не сбивать вкладку пользователя.

## Википедия: разбор HTML

- В окружении нет `bs4` и `lxml`, поэтому используется свой маленький DOM на `html.parser`, см. [`parse_list.py`](../scripts/wikipedia-japanologists/parse_list.py).
- Первый элемент с классом `mw-parser-output` бывает `<span>`. Разделы статьи лежат в `<section>`, нужные списки — их прямые `ul > li`.
- Категории: API `list=categorymembers`, QID — `prop=pageprops` пакетами по 50 (см. [`cats.py`](../scripts/wikipedia-japanologists/cats.py), [`qids.py`](../scripts/wikipedia-japanologists/qids.py)).

## Ad Marginem: весь магазин

Сайт на WooCommerce. Весь каталог (около 1140 позиций) отдаёт открытый API магазина: `/wp-json/wc/store/v1/products?per_page=100&page=N` — название, ISBN (`sku`), рубрики, атрибуты (год, перевод, оригинальное название), краткое описание, обложка. Автора и полной аннотации в API нет: авторы — в `/book-author-sitemap.xml` (страница автора перечисляет его книги), аннотация — на странице книги (`.text-annotation`, выходные данные — `.item-description`). Страницы книг весят около 0,5 МБ, поэтому их загружали только для отобранных книг. Серии: `/series-sitemap.xml` (например, `/series/hidebooks/`).
