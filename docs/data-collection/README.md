# Сбор данных: обзор процесса

Каталог наполнялся по запросам составителя: ссылка на страницу, файл или категорию → разбор → отбор → сопоставление с уже имеющимися записями → добавление → проверка на сайте → коммит. Ниже общий порядок. Подробности по отдельным темам — в соседних файлах.

## Общий порядок

1. **Получить данные.**
   - Простые страницы скачиваются `curl` или `urllib` с нормальным User-Agent.
   - Сайты с защитой или с требованием VPN открываются во встроенном браузере, а данные извлекаются JavaScript-ом на самой странице.
   - Подробнее: [Приёмы работы с сайтами](web-techniques.md).
2. **Разобрать** в структурированный JSON: название, авторы, переводчики, город, издательство, год, страницы, ISBN, серия, аннотация, обложка.
3. **Отобрать** по [критериям](../overview/scope-rules.md). Сомнительные случаи — спросить составителя.
4. **Сопоставить людей** с имеющимися авторами и переводчиками: по иероглифам, по набору слов имени, по фамилии и инициалу. Только если совпадения нет, создаётся новая запись. См. [Имена и люди](people-and-names.md).
5. **Найти дубли книг.** Нормализованное название (только буквы и цифры, ё → е) сравнивается по началу. Кроме того, должен совпасть год (±1) и хотя бы один автор или переводчик. Совпадение одного только названия ненадёжно: в каталоге много книг «Япония». У найденного дубля только дополняются пустые поля и дописывается источник.
6. **Добавить** новые книги **в конец** массива `books`, потому что номер карточки зависит от позиции. Указать `added` (сегодняшняя дата) и источник: `source`, `sources` или `links`.
7. **Жанр и теги.**
   - Типовые теги: `художественная` или `нехудожественная`, `переводная` или `на русском`.
   - Жанр и темы для массовых импортов назначаются по словам в названии (эвристика), см. [Известные проблемы](../maintenance/known-issues.md).
8. **Картинки** скачать в `images/` и записать в `_index.csv`, см. [Обложки и портреты](covers-and-portraits.md).
9. **Добавить запись в `news`** о крупном импорте.
10. **Проверить на сайте**:
    - страницы новых авторов и книг;
    - раздел, куда они попали;
    - консоль без ошибок;
    - время отрисовки больших страниц (около 0,6 с).
11. **Закоммитить и отправить** на GitHub. Сообщение коммита — по-русски, что и откуда добавлено.

## Как правился каталог

- **До 17 ноября** (примерно) каталог собирался конвейером `import_all.py`: исходный снимок `catalog_before_bulk.json`, данные каждого источника и файлы правок (`demo_fixes.json`, `author_fixes.json`, `extra_books*.json`) склеивались заново при каждом запуске. Рабочая папка с этими файлами была временной и очищена системой. Скрипты восстановлены из журнала сессии в [`docs/scripts/`](../scripts/README.md), но входных данных к ним нет.
- **Сейчас** `data/catalog.json` — единственный источник истины. Изменения вносятся небольшими Python-скриптами, которые читают JSON, меняют и сохраняют обратно. См. [Как вносить изменения](../maintenance/how-to.md).
