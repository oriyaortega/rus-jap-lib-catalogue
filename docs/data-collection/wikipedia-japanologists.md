# Японисты из Википедии

Импорт 23 ноября 2026 г. Источники:

- [Список русскоязычных японистов](https://ru.wikipedia.org/wiki/Список_русскоязычных_японистов) — 606 записей, у многих под именем перечислены работы (всего 1579);
- категории [Японисты Российской империи](https://ru.wikipedia.org/wiki/Категория:Японисты_Российской_империи) (16), [Японисты СССР](https://ru.wikipedia.org/wiki/Категория:Японисты_СССР) (102), [Японисты России](https://ru.wikipedia.org/wiki/Категория:Японисты_России) (73).

Скрипты лежат в [`docs/scripts/wikipedia-japanologists/`](../scripts/wikipedia-japanologists/). Это актуальные версии.

## Шаги

1. **`cats.py`** — участники категорий через API `list=categorymembers` → `cats.json`.
2. **`parse_list.py`** — HTML списка (скачан `curl`) разбирается своим DOM-парсером → `list.json`: для каждого человека строка-заголовок (имя, годы, степени), ссылка на статью и работы, включая вложенные подпункты.
3. **`match.py`** — разбор имён и сопоставление с каталогом → `persons.json`: 614 человек, 203 уже были в каталоге, 411 отсутствовали.
   - Имена бывают в форме «Фамилия, Имя Отчество», «Фамилия Имя Отчество», с инициалами. Есть запасной вариант из двух слов.
   - Поиск среди авторов и переводчиков по фамилии плюс имени или инициалам.
   - Псевдонимы и прежние фамилии в скобках считаются синонимами: «Аварин (Аболтин)».
4. **`books.py`** — работы → `wbooks.json`:
   - пропускаются статьи («//»), диссертации, авторефераты, депонированные рукописи, статьи с «С. N–N»: 288 записей;
   - книгой считается запись с выходными данными `Город: Издательство, год. N с.` или `Город, год. N с.`; около 100 записей без таких данных пропущено;
   - вложенные подпункты (другие издания, тома) пишутся в примечание книги;
   - если в ответственности есть «Пер.» и фамилия японоведа, он считается **переводчиком**, а японский автор берётся из начала названия («Кобаяси Исса. Стихи и проза»);
   - дубли: совпадение начала названия, год ±1 и общий человек (автор или переводчик) либо точное совпадение названия и года. Итог: 246 дублей, 808 новых.
5. **`qids.py`** — QID статей участников через `prop=pageprops` → `qids.json` (154).
6. **`apply.py`** — запись в каталог:
   - 411 новых авторов. У кого есть статья — указан `wikidata`, и сайт сам подтягивает биографию и портрет. У остальных короткая биография собрана из строки списка: годы жизни (только из части до первой учёной степени) и степени с годом («доктор исторических наук (1991)»), источник — список;
   - соавторы и японские авторы переводов тоже добавлены как авторы (около 48);
   - если человек есть в каталоге только как переводчик, но в книге он автор, для него создаётся авторская запись;
   - 797 книг с префиксом `wj`, источник «Википедия: «Список русскоязычных японистов»»;
   - у 240 имевшихся книг дописан этот источник;
   - у 70 имевшихся людей проставлен `wikidata`;
   - запись в `news`.

## Найденные ошибки и исправления

- Фраза в начале работы («Вклад И. А. Гошкевича…») принималась за список авторов. Теперь имена в начале работы засчитываются, только если среди них фамилия самого японоведа или его псевдоним.
- В регулярное выражение попал символ backspace (`\x08`): `\b`, записанный через heredoc. Из-за этого не определялись переводчики. Символ убран.
- «Сост.» без «пер.» ошибочно делало человека переводчиком. Теперь переводчиком считается только при наличии «пер».
- Подраздел «Долин, Переводы:» был отдельной записью; его объединили с основной записью Долина.
- Год защиты степени принимался за год рождения.
- У Аварина не находились книги из-за псевдонима Аболтин; синонимы в скобках теперь учитываются.

## Не разобрано

- Три имени нестандартного вида: Ле Куанг Ань, Пуиг Порталь Баир Элоевич, Чан Су Бу.
- Люди, у которых в списке только статьи, есть в каталоге без книг.
- Жанр и тематические теги назначены по словам в названии. Например, «Кофейные зерна» Коваленина ошибочно записаны как исследование.
- Псевдонимы в начале названий («Хаяма У. (псевд.) …») позже вынесены в примечание «Издано под псевдонимом У. Хаяма».
