# Заметки об инструментах

Особенности окружения (Windows 11, Git Bash и PowerShell, Python 3.12), на которые не раз натыкались при работе.

## Python

- Запуск с `-X utf8`, иначе `print` кириллицы падает с `UnicodeEncodeError` (cp1252). Переменная `PYTHONIOENCODING=utf-8` тоже помогает, но не вместе с `-I`.
- Скрипты, читающие скачанные файлы, запускать с `-I` (изолированный режим): чтобы случайный `json.py` в папке не подменил модуль. При `-I` папка скрипта не попадает в `sys.path`, поэтому для своих модулей нужно `sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))`.
- `bs4` и `lxml` нет; HTML разбирается `html.parser` (см. [приёмы](../data-collection/web-techniques.md#википедия-разбор-html)). PDF — `pymupdf`. Картинки — Pillow.
- Файлы со списками id сохранять с `newline='\n'`: CRLF ломал `curl` при чтении списка.

## Bash (Git Bash)

- Большие Python-скрипты в heredoc (`python - <<'EOF'`) иногда падают с «unexpected EOF». Надёжнее записать скрипт в файл и запустить его.
- Внутри heredoc `\b` в регулярном выражении однажды превратился в настоящий символ backspace. Регулярные выражения лучше держать в файлах.
- `sed` на файлах с регулярными выражениями JS/Python ненадёжен. Используйте замену строк в Python (с `assert s.count(old) == 1`) или редактор.

## Git

- Push только от `oriyaortega`. Remote настроен как `https://oriyaortega@github.com/oriyaortega/rus-jap-lib-catalogue.git`. Вход выполняет сам владелец через браузер.
- Предупреждения «LF will be replaced by CRLF» безвредны.
- Откат неудачного скрипта до коммита: `git checkout data/catalog.json`.

## Браузер

- Если на странице вдруг рисуются все записи сразу, проверьте, не остался ли флаг отключения ленивой отрисовки: `localStorage.getItem('lazy')` (его ставит сверка со старой версией).
- После многих горячих обновлений (HMR) dev-сервер иногда отдаёт устаревший модуль (ошибка «… is not defined» при верном коде) — перезапустите `npm run dev` и обновите страницу без кэша.

- Данные сайта кешируются. После правки каталога: `await fetch('data/catalog.json',{cache:'reload'}); location.reload()`. Файлы JS и CSS в сборке получают хеш в имени, поэтому кеш сбрасывается сам.
- Смена `#` в адресе не перезагружает данные.
- Скрытая вкладка замедляет таймеры.
