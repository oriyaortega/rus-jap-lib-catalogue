# Известные проблемы и что можно доделать

Состояние на 23 ноября 2026 г.

## Данные

- **Жанры и теги** у массовых импортов назначены автоматически по словам в названии: ИВ РАН (`iv`), библиографии (`bj*`), японисты (`wj`). Нужна выборочная проверка. Пример ошибки: «Кофейные зерна» Коваленина записаны как исследование.
- **Склейки записей в печатных библиографиях**: в названиях `bja1`, `bjb2979`, `bjb2980`, `bjb4038` попали заголовок раздела или соседняя запись. Вероятно, есть и другие. Поиск: номера вида «2971.» внутри `title_ru`.
- **Без года**: 328 книг, в основном из библиографий.
- **Издания с Фантлаба (`fe`)** добавлены автоматически (`docs/scripts/fantlab/import_editions.py`):
  - обложки не скачаны в `images/`, а показываются по ссылке с Фантлаба (`cover` = `cover_src`);
  - жанр — по видам произведений, у сборников без произведений каталога — «новеллы»; у 41 антологии нет автора;
  - не вошли 73 сборника, где японских произведений меньше половины (зарубежная фантастика и детективы, «Манъёсю» — вошли), и журналы — их список в отчёте скрипта;
  - 35 новых переводчиков без сведений; возможен дубль `logachev` / `logachevserge` (по Фантлабу это разные люди), у `feldman` и `feldmann` дубль был и раньше;
  - 123 новые серии (`fls…`) — серии Фантлаба, в том числе издательские («Мир Харуки Мураками»).
- **Без обложки**: около 3070 книг, в основном старые издания из библиографий. У `gs35` вместо обложки превью LiveLib. У `x92`/`lb679330` нет настоящей обложки.
- **Без ISBN**: часть книг с 1990 года, остальные изданы до появления ISBN.
- **Авторы без сведений**: около 1176 авторов без `bio` и `wikidata`, в основном известные по инициалам из библиографий. Около 25 японских авторов без иероглифов и около 20 иностранных без латиницы.
- **Произведения** (`works`): 13 иностранных без оригинального названия, 12 без года.
- **Не разобраны** японисты Ле Куанг Ань, Пуиг Порталь Б. Э., Чан Су Бу.
- **Марчук, книга 2026 г.**: нет издательства и ISBN.
- **Ad Marginem**: книги 2027 г. отмечены как готовящиеся; при выходе нужно обновить.
- **Демонстрационные книги** b1–b13 сверены с Фантлабом и оставлены в каталоге.
- **«Другое издание»**: у `ll6` нет обратной ссылки на `ll2`.

## Сайт

- **Произведения без названия**: у двух произведений в содержании книги `x37` нет названия (`contents[].t`); на странице книги и переводчицы В. Марковой они показаны пустыми строками. Старая версия сайта на странице Марковой из-за этого падала, новая работает (см. [Переход на React](../technical/react-version.md)). Лучше дописать названия в данных.
- Записи `news` не выводятся (раздел «Новости» убран).
- Длинные списки рисуются порциями при прокрутке, поэтому поиск по странице в браузере (Ctrl+F) находит только уже отрисованное. Для поиска по каталогу есть раздел «Поиск».
- Тестами покрыта только логика (`src/lib/`, `src/router.ts`); React-компоненты не тестируются, их проверяли сверкой со старой версией.
- Портреты из Википедии без локальной копии загружаются с Викисклада. Если он недоступен, портрета не будет.
- Страница «О сайте» (текст обновлён 25 ноября 2026 г.) называет основой три тома «Библиографии Японии», но из источников импорта перечисляет только первый этап: нет ИВ РАН, Ad Marginem и японистов из Википедии.
- На странице переводчика книги внутри группы автора идут по году, а не по алфавиту, как у автора.

## Воспроизводимость

Исходные выгрузки (JSON с сайтов, CSV таблицы, тексты PDF) были во временной папке и утеряны. Скрипты в [`docs/scripts/`](../scripts/README.md) показывают, как всё делалось, но заново собрать каталог из первоисточников ими нельзя. Каталог `data/catalog.json` в git — единственная полная копия данных.
